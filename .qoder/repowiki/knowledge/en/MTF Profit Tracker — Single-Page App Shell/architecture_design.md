The app is a classic single-page application with no framework: `main.html` declares the DOM skeleton (header, page sections for trades/past/market/gold/calendar/settings/more, sheet panels, dialog), `main.js` re-exports every symbol from `window.MTFComponents` (provided by `shared_runtime`) and `window.MTFDb`, then wires broker configs, live NSE/Yahoo stock search, trade form auto-suggest, and view routing. Feature pages under `features/` register themselves through the global `MTFRegister`/`MTFComponents` registry consumed by the shell. Build/dev tooling in `build_and_scripts/` (`build-production.js`, `shared/scripts/sync-manifest.js`, `verify.js`, `github-sync.js`, `git-save*.js`) keeps the script manifest in sync with disk, minifies assets, bumps versions from `app-version.json`, and runs Playwright smoke tests (`playwright.config.js`). `pages.json` is the manifest consumed by the sync/build scripts; `firestore.rules` configures the backend used by the shared DB layer. The root `package.json` exposes a unified CLI (`npm run all` = repair + build + verify) and dev server entry points (`start`, `dev`, `production`).
