Each file is a self-contained IIFE that reads helpers from `global.MTFComponents` and `global.MTFAppHelpers`, then publishes its public API via `global.MTFRegister(...)`. Internal layering follows an organism/molecule split: `app-shell.js` provides the chrome (BottomBar, Sheet/CupertinoPane wrapper, AppDialog/Bootstrap Modal, AppHeader); `trade-list.js` composes molecules (P&L, leverage, detail rows, actions) into list-item and grouped-list organisms; `trade-sheets.js` implements per-trade edit/view sheets (view, charges, interest, target sell, buy price, leverage, hold dates); `trade-modal.js` is the add/edit transaction sheet orchestrating form state and preview calculations; `search-page.js` renders filtered trade lists; `router.js` wires Page.js routes to `global.renderAppPage`. Dependency direction is one-way: this module depends on `MTFComponents` (rendering primitives, toast, date helpers) and `MTFAppHelpers` (data accessors like `getTransaction`, `calculateTrade`, `refreshTradeListViews`) — it never imports sibling features, keeping it truly cross-feature.
