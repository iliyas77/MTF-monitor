Flat collection of standalone Node scripts under `shared/scripts/`, each invoked directly via `node` or npm scripts. Two sub-families coexist:

- Manifest repair: `sync-manifest.js` walks `shared/lib/`, `components/`, `features/`, `shared/db/` to rebuild `shared/scripts/manifest.json` and rewrites the `<script>` block between the `<!-- COMPONENT SCRIPTS -->` … `main.js` markers in `main.html`. It enforces a hard dependency order via `preferredLibOrder` / `preferredDbOrder` / `preferredComponentsOrder` / `preferredFeaturesOrder` (registry files first, then alphabetized rest).
- Health verification: `verify.js` is the orchestrator — it composes three pluggable stages (`verify-integrity.js`, build step, `verify-smoke.js`) through a shared `verify-report.js` reporter that records `{ok,warn,name,detail}` entries and prints a colored summary. `verify-integrity.js` asserts required sources, Bootstrap CDN links, `_variables.css`, manifest-orphan parity, per-module `MTFRegister`/`MTFDbRegister` calls, JS syntax via `node --check`, and a fixed `shared/db/` layout.
- Browser smoke: `verify-smoke.js` spins up an in-process `http` server serving `production.html`, launches Playwright Chromium in a 390×844 mobile viewport, seeds trades via `window.MTFDb.saveStorageLocal`, and asserts navigation across Trades → Watchlist → Calendar → More pages plus UI chrome (filter sheet, trade detail sheet, search, add-trade modal).
- Developer save helpers: `git-save.js` creates a dated `save/<date>-with-<slug>` branch, bumps version + builds production, commits, pushes, and opens a PR against `Dev` via `gh`; `git-save-local.js` does the same on the current branch without creating a new one. Both share `SECRET_PATTERNS` to refuse committing `.env`/`credentials.json`/`.pem`/`id_rsa`/`.p12`.
- Ticket sync: `github-sync.js` parses `ticket.txt` for `### [NEW]` blocks, creates GitHub issues via `gh issue create`, adds them to GitHub Project #1 owned by `iliyas77`, updates `TICKETS.md`, and clears `ticket.txt`.

Dependency direction is one-way: `verify.js` imports the other verify-* modules; no cross-imports among git-save / github-sync / sync-manifest. All scripts resolve `ROOT = path.join(__dirname, '../..')` so they operate from the repo root.
