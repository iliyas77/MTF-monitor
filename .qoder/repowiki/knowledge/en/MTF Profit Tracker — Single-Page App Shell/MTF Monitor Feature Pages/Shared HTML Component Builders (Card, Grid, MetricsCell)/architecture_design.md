Three independent UMD-style IIFE modules (`card.js`, `grid.js`, `metrics-cell.js`) each export a single object via the shared registration protocol: if `global.MTFRegister` exists they call it with `{ Name }`; otherwise they attach to `global.MTFComponents` (or `global.MetricsGrid`). There is no bundler or inter-file import — files are loaded independently by the host page. `metrics-cell.js` additionally depends on two sibling components exposed through `global.MTFComponents` (`renderIcon`, `escapeHtml`) at runtime, establishing a one-way dependency direction from this module outward. Each builder exposes a `build(params)` function returning an HTML string; there is no DOM manipulation inside the builders themselves, keeping them pure renderers suitable for SSR or pre-rendered templates.
